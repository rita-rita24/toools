レビュー結果

設定

外観

エディターの文字サイズ

String name = "sample";
int count = 3;
boolean active = true;

表示設定はこのブラウザーに保存され、ほかのツールにも適用されます。

使い方

  1. 言語を選ぶ

    入力欄の上でJavaまたはJavaScriptを選択します。

  2. コードを貼り付ける

    入力すると自動で解析し、右側にレビュー結果を表示します。行番号から該当箇所を確認できます。

  3. 指摘を確認する

    各指摘を開いて説明を確認します。「クリア」で入力を消した場合は「元に戻す」で復元できます。

外観や文字サイズは、右上の「設定」から変更できます。
