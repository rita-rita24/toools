sb.addQuery 双方向変換ツール

通常テキストとsb.addQuery形式を相互変換します。どちらの欄も編集できます。

設定

外観

大きさ

sb.addQuery(" SELECT * ");
sb.addQuery(" FROM users ");
sb.addQuery(" WHERE id = 42 ");

使い方

  1. どちらかの欄へ入力する

    左に通常テキスト、右にsb.addQuery形式を入力します。編集した側から、もう一方へ自動変換します。右欄は sb.addQWPNB(...) と、Javaのテキストブロック（sb.addQuery(""" ～ """);）が混在していても読み取ります。左欄から作る右欄は sb.addQuery 形式です。

  2. 変換内容を確認する

    改行、空行、ダブルクォートやバックスラッシュを含む内容を確認します。各行は改行なしで連結されるため、SQLの行コメント（--）は /* */ に置き換えます。sb.addQuery(" A = ? ", today); のような引数付きの行は A = ? /* today */ と表示し、左から戻すと引数へ戻します。連結を含むJava行や、? と引数の数が合わない行は変換せず原文のまま残します。両方の欄を編集できます。

  3. 結果をコピーする

    右上の「コピー」でsb.addQuery形式をコピーします。「クリア」は両方の欄を空にし、次に入力するまで「元に戻す」で復元できます。変換できない行は原文のまま残し、右欄の上に「未変換」の件数を表示します。入力はこのブラウザーに保存され、次に開いたときに復元されます。

外観や文字サイズは、右上の「設定」から変更できます。
