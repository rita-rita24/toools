sb.addQuery 双方向変換ツール

通常テキストとsb.addQuery形式を相互変換します。どちらの欄も編集できます。

設定

外観

エディターの文字サイズ

sb.addQuery(" SELECT * ");
sb.addQuery(" FROM users ");
sb.addQuery(" WHERE id = 42 ");

表示設定はこのブラウザーに保存され、ほかのツールにも適用されます。

使い方

  1. どちらかの欄へ入力する

    左に通常テキスト、右にsb.addQuery形式を入力します。編集した側から、もう一方へ自動変換します。

  2. 変換内容を確認する

    改行、空行、ダブルクォートやバックスラッシュを含む内容を確認します。両方の欄を編集できます。

  3. 結果をコピーする

    右上の「コピー」でsb.addQuery形式をコピーします。「クリア」は両方の欄を空にします。

外観や文字サイズは、右上の「設定」から変更できます。
